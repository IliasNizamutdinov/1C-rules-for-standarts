# Пример. Запрос к регистру накопления

Имена регистра `ОстаткиТоваров`, измерения `Номенклатура` и ресурса `Количество` здесь условные. В конфигурации их нужно проверить.

## Запрос

«Напиши запрос остатка по номенклатуре на дату из регистра накопления остатков.»

## Какие правила подключать

- `20-queries`: `STD-QRY-001`, `STD-QRY-008`, `STD-QRY-012`.
- `30-data-architecture`: если остаток потом меняет проведение, добавить `STD-DATA-004`.
- `00-policy`.

## Что проверяет агент

- Ключевые слова запроса в верхнем регистре.
- У виртуальной таблицы `Остатки` заполнены период и отбор, а не только `ГДЕ` снаружи.
- Псевдоним источника понятный.
- В выборке только нужные поля, без `ВЫБРАТЬ *`.
- Если запрос внутри проведения меняет движения, до чтения стоит управляемая блокировка. Для показа остатка на форме блокировка не следует из одного только факта запроса.

## Отчет

```text
Официальные требования
STD-QRY-012 соблюден: отбор номенклатуры передан параметром виртуальной таблицы Остатки.
Источник: https://its.1c.ru/db/v8std/content/657/hdoc

Если тот же запрос стоит в проведении и по нему списывается товар, отсутствует блокировка STD-DATA-004.
Это отдельное обязательное условие ответственного чтения, а не свойство любого запроса остатков.

Официальные методические рекомендации
STD-QRY-010: в выборке нет лишних полей. Статья #std729 — методическая рекомендация.

Инженерные рекомендации
Нет.

Требования проекта
Не заданы.

Нужна проверка по источнику
Имя регистра ОстаткиТоваров в конфигурации не подтверждено.
```

## На что похож код

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	Остатки.Номенклатура КАК Номенклатура,
|	Остатки.КоличествоОстаток КАК Количество
|ИЗ
|	РегистрНакопления.ОстаткиТоваров.Остатки(&Период, Номенклатура = &Номенклатура) КАК Остатки";
Запрос.УстановитьПараметр("Период", ДатаОстатка);
Запрос.УстановитьПараметр("Номенклатура", Номенклатура);
```

Запрос не заменяет проведение и не содержит блокировку. Ее добавляют только в сценарии ответственного чтения.
