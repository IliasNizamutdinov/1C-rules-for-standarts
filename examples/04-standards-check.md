# Пример. Проверка кода на соответствие стандартам

## Запрос

«Проверь фрагмент. Ничего не переписывай.»

```bsl
Процедура ПередЗаписью(Отказ)
	Отказ = Ложь;
	Если Не ЗначениеЗаполнено(Контрагент) Тогда
		Отказ = Истина;
	КонецЕсли;
КонецПроцедуры
```

## Какие правила подключать

`00-policy`, `10-modules`, `30-data-architecture`.

## Что проверяет агент

Смотрит только то, что можно подтвердить правилом. Не предлагает заодно переименовать документ и не вызывает БСП.

## Отчет

```text
Официальные требования
- STD-MOD-011. Строка Отказ = Ложь может сбросить отказ, установленный раньше.
  Место: первая строка ПередЗаписью.
  Источник: https://its.1c.ru/db/v8std/content/686/hdoc
- STD-MOD-011. Отказ становится Истина без сообщения пользователю.
  Источник тот же, пункт 3, со ссылкой на информирование пользователя #std400.
- STD-DATA-008. Нет выхода при ОбменДанными.Загрузка.
  Источник: https://its.1c.ru/db/v8std/content/773/hdoc
- STD-UI-001. Для управляемого приложения причину нужно показать через СообщениеПользователю.
  Источник: https://its.1c.ru/db/v8std/content/418/hdoc
  Применимость STD-UI-001 — управляемое приложение. Для обычного приложения это нужно перепроверить.

Нет.

Нет.

Не заданы.

Код не запускался в платформе.
```
