# Пример. Процедура в модуле объекта документа

Фрагмент показывает размещение и форму процедуры. Имена документа и регистра в конкретном проекте нужно взять из метаданных, а не из этого примера.

## Запрос

«Добавь в модуль объекта документа экспортную функцию, которая возвращает сумму табличной части Товары. Код должен соответствовать правилам 1С.»

## Какие правила подключать

- `00-policy` — как называть типы замечаний.
- `10-modules` — имя, комментарий экспортной функции, место в модуле.
- `30-data-architecture` — функция про экземпляр документа остается в модуле объекта (`STD-ARCH-002`).

Запросы, права и форма здесь не нужны, пока функция не читает базу и не открывает форму.

## Что проверяет агент

- Функция лежит в области программного интерфейса, а не среди обработчиков проведения.
- Имя построено от результата, а не от слова «Получить».
- У экспортной функции есть комментарий с описанием и возвращаемым значением (`STD-MOD-009`).
- Нет буквы «ё», отступ табуляцией, один оператор в строке.
- Функция не делает запрос, если сумма уже есть в табличной части объекта.

## Отчет

```text
Официальные требования
Нарушений в добавленной функции не видно.
Применены STD-MOD-005, STD-MOD-009, STD-ARCH-002.

Официальные методические рекомендации
STD-ARCH-002: функция работает с уже загруженным экземпляром, поэтому модуль объекта уместен.
Это методическая рекомендация #std486.

Инженерные рекомендации
Замечаний нет.

Требования проекта
Не заданы.

Нужна проверка по источнику
Имя табличной части Товары и реквизита Сумма не сверялись с метаданными конфигурации.
```

## На что похож код

```bsl
// Возвращает сумму строк табличной части Товары.
//
// Возвращаемое значение:
//  Число - сумма по колонке Сумма. Для пустой табличной части возвращает 0.
//
Функция СуммаТоваров() Экспорт

	Результат = 0;
	Для Каждого СтрокаТоваров Из Товары Цикл
		Результат = Результат + СтрокаТоваров.Сумма;
	КонецЦикла;

	Возврат Результат;

КонецФункции
```

Это учебный фрагмент, а не универсальная процедура проведения.
