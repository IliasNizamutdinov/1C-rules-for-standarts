# Правила разработки 1С

Этот файл задает порядок работы OpenCode в проекте, куда установлены правила. Сам по себе он не содержит весь корпус требований: OpenCode не подставляет файл только потому, что на него есть ссылка.

Рабочие тексты правил загружаются через `opencode.json`, поле `instructions`. Проверьте, что в нем перечислены:

- `opencode/instructions/00-policy.md`
- `opencode/instructions/10-modules.md`
- `opencode/instructions/11-language.md`
- `opencode/instructions/20-queries.md`
- `opencode/instructions/30-data-architecture.md`
- `opencode/instructions/40-client-server-security.md`
- `opencode/instructions/50-forms-applied.md`

Файл `opencode/instructions/90-project-template.md` не подключают, пока проект не заменит шаблон своими требованиями.

## Как различать правила

- `OFFICIAL_STANDARD` — формулировка, сверенная с текстом конкретного стандарта фирмы «1С» на https://its.1c.ru/db/v8std. У нее есть идентификатор стандарта, URL, дата проверки и сила нормы.
- `ENGINEERING_RECOMMENDATION` — дополнительное указание этого репозитория. Его нельзя называть стандартом фирмы «1С».
- `PROJECT_REQUIREMENT` — требование конкретной конфигурации или организации. Шаблон в репозитории выключен.

Если статья помечена как методическая рекомендация или так помечена часть пунктов, в отчете так и пишите. Не повышайте рекомендацию до обязательного требования.

## Проверка кода

Отчет делите на четыре группы:

1. Нарушения официальных стандартов: идентификатор правила, место, в чем проблема, ссылка на источник.
2. Нарушения инженерных рекомендаций: те же поля и прямая пометка, что это рекомендация.
3. Нарушения требований проекта: только для включенных проектных правил.
4. Вопросы, для которых в каноне нет прочитанного источника. Здесь нельзя писать «нарушен стандарт 1С».

Перед изменением модуля прочитайте соседний код. При правке оформления не меняйте учетный результат. Не создавайте объекты метаданных, которых нет в конфигурации.

## Что считать загруженным

Откройте новый сеанс OpenCode в корне проекта и спросите, какие файлы инструкций подключены. В ответе должны быть семь файлов из `instructions`, а не только этот `AGENTS.md`. Если перечислен только `AGENTS.md`, конфигурация OpenCode не прочитала `opencode.json`.

Для OpenCode V2 каталог инструкций описан на https://opencode.ai/docs/rules/ и https://opencode.ai/v2/docs/instructions/. Версия V2 не подставляет `CLAUDE.md` вместо `AGENTS.md`.
